# Dan 的生日卡片

純 HTML、CSS、JavaScript 的靜態網頁，不需要安裝套件或建置。

在專案資料夾執行 `python3 -m http.server 3000 --bind 127.0.0.1`，開啟 http://localhost:3000/ 預覽。JavaScript 模組需要透過 HTTP 預覽。

## 修改內容

`card-content.js` 集中管理背景圖片、標題、副標題、底部文字、信件、庫洛米圖片與相簿順序。修改 `letter` 即可更新信件；多行內容可使用 JavaScript 的反引號字串。`letterSticker` 設定貼圖與要接在哪句文字之後。信件採用清松手寫體 2（Max 補字版），以段落排版；402px 寬的手機畫面內文約 11.6px，橫線跟隨各段行距；目前內容在 402 × 700px 的模擬可視區域內可完整顯示整張卡片。信紙隨文字自然增高，較窄螢幕或放大文字時仍可捲動閱讀。字型子集與授權存放於 `assets/fonts/`；新增信件用字時需檢查字型覆蓋並重新產生子集，詳見該目錄的 README。

相簿依 `assets/photos/010.webp` 到 `assets/photos/450.webp` 排列，共 45 張，第一張與原草圖相同，450 是最後一張。網頁使用長邊不超過 1600px、品質 80 的 WebP，原始照片保留在 `us/`。卡片使用 `assets/photos/thumbs/` 中長邊 480px、品質 72 的縮圖；放大後先顯示縮圖，再換成清晰照片。新增照片時需同時產生清晰版與縮圖 WebP，並更新 `card-content.js` 的照片數量。

手機可在相框照片或放大照片上左滑下一張、右滑上一張；卡片上的上下滑動保留頁面捲動功能。也可使用前後按鈕、在相簿取得焦點時使用鍵盤左右鍵，或點擊照片放大；按 Escape 關閉放大畫面。頁面載入後，以兩個並行下載逐批預載縮圖；只有打開相簿後才下載目前與下一張清晰照片。放大檢視使用 `card-content.js` 的 `albumBackground`：`assets/album-background.jpg` 從確認的示意圖整理，保留淡紫紋理與下方兩人開車的場景；構圖以 924 × 1701 比例縮放，第一張照片填滿參考圖的相框，其餘照片完整顯示。內外標題共用本機 Almendra 字型，相簿標題為 Along the Way。並支援原生水平滑動，下載清晰照片時保留縮圖；失敗可按「重試」。支援減少動態效果設定。

庫洛米顯示使用 576px 透明 WebP（`assets/kuromi.webp`），原始 PNG 保留供日後調整；網站圖示另用 64px PNG。若更換角色，需同步更新 `card-content.js`、`index.html` 的預載圖片與網站圖示。

## 音樂試聽版

頁面載入時嘗試自動播放；若瀏覽器限制有聲自動播放，第一次點擊頁面時開始。音符按鈕可暫停或重新播放。外頁按鈕在白色信紙外側的右下角，相簿按鈕固定在下方兩人開車插畫的右下角、翻頁列上方，不隨照片尺寸移動；圖示為 16px，點擊範圍為 44px。沒有文字標籤，播放時顯示音符，暫停或尚未開始時顯示音符加斜線。卡片循環播放主歌，打開相簿切換為循環副歌，關閉相簿則從主歌開頭播放；切換時以 0.45 秒淡入淡出。暫停後開關相簿不會自行播放。切到其他分頁或 App 時停止音樂，回來後可再按播放。

`card-content.js` 的 `music` 設定兩段音檔路徑，`components/music.js` 共用播放狀態與兩處按鈕。播放與靜音使用兩個固定 SVG 圖示切換，不使用遮罩。使用 Web Audio 的緩衝音檔循環，音量目前為 48%；第一次播放才下載音檔，當前段落開始播放後預載另一段，切換不重複下載。載入失敗時按鈕可重試。

音檔由根目錄的 `2026-10-24 15-34-30.mov` 匯出為 160 kbps MP3：主歌取錄影 14.4–56.8 秒，副歌取 78.0–98.2 秒（從「我看著妳的臉」這一句開始）。前後各做 0.12／0.45 秒淡入淡出，主歌切點已經使用者試聽確認，副歌依使用者指定的起句及錄影字幕重新定位。兩個音檔合計約 1.2 MB，位於 `assets/audio/`。原始錄影保留在本機並加入 Git 忽略清單，網站只使用裁切後的 MP3。

## 元件

每個元件的程式與樣式放在 `components/` 的同名 `.js`、`.css` 檔案：

| 元件 | 檔名 | 可調整內容 |
| --- | --- | --- |
| 背景 | `background` | 畫作、疊色、裁切 |
| 主標題 | `title` | 文字、字體、位置 |
| 副標題／底部文字 | `subtitle` | 獨立文字內容與位置 |
| 中央信紙 | `letter` | 信件、白紙造型與淡線 |
| 相簿 | `album` | 相框、切換按鈕、放大檢視 |
| 庫洛米 | `character` | 插畫、大小與位置 |
| 裝飾 | `decorations` | 星星與外框 |
| 音樂 | `music` | 主歌／副歌循環、播放按鈕、淡入淡出 |

`card.js` 組合各元件；`styles.css` 管理整體版面。這是程式與內容設定的拆分，沒有另建拖拉編輯器。

## 之後發布

使用相對路徑，可部署在 GitHub Pages 的專案網址下。網頁需要 `index.html`、`card.js`、`card-content.js`、`styles.css`、`components/`、`assets/`（含 45 張網頁用照片）和使用中的 `artwork/artwork2.jpg`。

本機備份 ZIP、`us/duplicates/` 與 CSV 對照表不供網頁使用，發布時不需要上傳。
