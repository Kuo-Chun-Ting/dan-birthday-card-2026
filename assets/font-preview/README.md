# 手寫字體比較用子集

此目錄僅供 `font-preview.html` 比較使用。已選用的 D 字型移至 `../fonts/letter-handwriting.woff2`，正式卡片與比較頁共用同一份檔案。

比較使用的 WOFF2 檔由以下來源縮減為目前信件與比較樣本的用字；各字型的原始著作權與授權資訊均保留。此目錄字型的內部名稱為 Birthday Preview A、B、C、E，正式採用的 D 為 Birthday Letter Handwriting。

- `wenkai.woff2`：[霞鶩文楷 TC](https://github.com/lxgw/LxgwWenkaiTC)，來源為 Google Fonts 的 `ofl/lxgwwenkaitc/LXGWWenKaiTC-Regular.ttf`。
- `iansui.woff2`：[芫荽](https://github.com/ButTaiwan/iansui)，來源為 `fonts/ttf/Iansui-Regular.ttf`。
- `chenyu.woff2`：[辰宇落雁體 2.0 細體](https://github.com/Chenyu-otf/chenyuluoyan_thin)，來源為 `ChenYuluoyan-2.0-Thin.ttf`。
- `../fonts/letter-handwriting.woff2`：[清松手寫體 2 補字版](https://github.com/max32002/JasonHandWritingFonts)，來源為 `webfont/JasonHandwriting2-Regular.woff2`。原作者版本缺少信件中的「墩」，此處採用 Max 的非官方開源補字版。
- `jason9.woff2`：[清松手寫體 9](https://github.com/jasonhandwriting/JasonHandwriting)，來源為官方儲存庫的 `JasonHandwriting9.ttf`。

各字型的完整授權請見同目錄的 `*-license.txt`。若變更信件文字，需重新產生子集，避免新增的字退回系統字型。
