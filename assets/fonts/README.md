# 信件手寫字體

`letter-handwriting.woff2` 是使用者選定的 D：清松手寫體 2（Max 補字版）。

- 原作者：游清松；補字版維護者：Max。
- 來源：https://github.com/max32002/JasonHandWritingFonts ，`webfont/JasonHandwriting2-Regular.woff2`。
- 本機以 fontTools 縮減為目前信件用字，包含「墩」；內部字型名稱改為 Birthday Letter Handwriting。
- 字型與授權隨網站一起提供，瀏覽時不需向外部字型服務下載。
- 完整授權見 `letter-handwriting-license.txt`。

修改信件文字後，應檢查字型覆蓋；新增用字需從來源字型重新產生 WOFF2 子集，否則會以系統字型顯示缺少的字。
